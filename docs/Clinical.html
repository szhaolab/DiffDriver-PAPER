Context-associated driver genes across clinical traits (Fig. 4a)

DiffDriver was applied across 20 tumor types to six clinical traits — Tumor Mutational Burden (TMB), Fraction of Genome Altered (FGA), Aneuploidy Score, Diagnosis Age, Disease-specific Survival, and Progression-free Survival. For the pan-cancer summary, the DiffDriver likelihood-ratio p values for every gene × tumor-type test are pooled within each trait and a Benjamini–Hochberg correction is applied across tumor types within each trait (data/clinical_pertrait_pvalues.tsv; 1,968 tests, 185 unique driver genes). A gene is called significant if it passes BH FDR < 0.1 in at least one trait.

library(ggplot2)
cl <- read.table("data/clinical_pertrait_pvalues.tsv",
                 header = TRUE, sep = "\t", stringsAsFactors = FALSE)
cl <- cl[!is.na(cl$dd.p), ]
cl$fdr <- ave(cl$dd.p, cl$trait, FUN = function(x) p.adjust(x, "BH"))
sig   <- cl[cl$fdr < 0.1, ]
n_bg  <- length(unique(cl$gene))
n_sig <- length(unique(sig$gene))
cat("Driver genes tested (background):", n_bg, "\n")
Driver genes tested (background): 185 
cat("Genes significant in >=1 trait (BH FDR < 0.1):", n_sig,
    sprintf("(%.1f%%)\n", 100 * n_sig / n_bg))
Genes significant in >=1 trait (BH FDR < 0.1): 45 (24.3%)

45 of 185 driver genes (24.3%) show differential selection for at least one of the six clinical traits.

Fig. 4a — driver genes per clinical trait

lab <- c(TMB.nonsynonymous = "TMB", Fraction.Genome.Altered = "FGA",
         Aneuploidy.Score = "Aneuploidy", Diagnosis.Age = "Patient age",
         Months.of.disease.specific.survival = "Disease-specific survival",
         Progress.Free.Survival.Months = "Progression-free survival")
cnt <- sapply(names(lab), function(tr) length(unique(sig$gene[sig$trait == tr])))
df  <- data.frame(trait = factor(unname(lab), levels = unname(lab[order(-cnt)])),
                  n = as.integer(cnt))
ggplot(df, aes(trait, n, fill = trait)) +
  geom_col(width = 0.7) +
  geom_text(aes(label = n), vjust = -0.3, size = 4) +
  labs(x = NULL, y = "No. driver genes (BH FDR < 0.1)") +
  ylim(0, max(cnt) * 1.15) +
  theme_classic(base_size = 12) +
  theme(legend.position = "none",
        axis.text.x = element_text(angle = 30, hjust = 1))
